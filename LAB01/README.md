# Занятие №1
## Создание персональной директории

Создайте директорию, назава её своей фамилией (требования: английский язык, строчные буквы) в домашнем каталоге. Эта директория в дальнейшем будет служить вашим персональным каталогом;

Перейдите туда. В дальнейшем работайте только в вашем персональном каталоге;

Проверьте¸ что вы действительно находитесь в персональном каталоге;

Создайте пустой файл about.md;

Заполните его в **kate**:
ФИО, Курс, Направление, Доп. информация при желании;

Посмотрите содержание вашего персонального каталога через терминал;

Создайте копию about.md (назовите его about.md.bak);

Создайте хранилище запасных файлов (директорию) backup/;

Переместите туда файл-копию (about.md.bak);

Посмотрите содержимое backup/, НАХОДЯСЬ ПРИ ЭТОМ В домашней директории (~);

Посмотрите содержание файла about.md.bak НАХОДЯСЬ ПРИ ЭТОМ В домашней директории (~);

Переместитесь в корневой каталог;

Из корневого каталоге переместитесь в backup/ одной командой;

Создайте в персональной директорию папку trash/ и удалите её двумя способами.
