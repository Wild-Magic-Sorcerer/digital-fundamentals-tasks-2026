# Основы цифровых технологий 2026

Преподаватель: Горелов Сергей Васильевич.

### Команды:

| Команда | Функция |
|---|---|
| cd | Перемещение (по каталогам). |
| cp | Копирование. |
| mv | Перемещение (файлов и каталогов). |
| touch | Создание файла. |
| rm | Удаление. |
| rmdir | Удаление каталогов. |
| mkdir | Создание каталога. |
| pwd | Вывод текущей директории. |
| ls | Просмотр содержимого в каталоге. |
| cat | Вывод содержимого файла. |
| history | Вывод истории. |

### Особые обозначения:

| Обозначение | Функция |
|---|---|
| / | Корневой каталог. |
| ./ | Текущий каталог. |
| ../ | На один каталог назад. |
| ~/ | Домашний каталог. |
