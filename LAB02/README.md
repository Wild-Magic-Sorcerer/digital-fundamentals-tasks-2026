# Задание №2
## Основы работы с текстом и ссылками в Linux

### Текстовым редактором kate пользоваться запрещено! Все изменения должны производиться только через командную строку!

Проверьте, что ваша персональная директория названа правильно. Если это не так, переименуйте её. Перейдите в свою персональную директорию. Все дальнейшие действия проводите только в ней.

Создайте файл `students.txt` и запишите в него список минимум из 10 студентов вашей группы (ФИО, каждое значение с новой строки). Посмотрите содержимое файла `students.txt`, не используя `cat`.

Добавьте в конец файла строку с номером вашей группы. Добавьте к конец файла строку с сегодняшней датой.

Выведите только первые 3 строки файла `students.txt`.

Выведите только последние 5 строк файла `students.txt`.

Выведите только одну пятую строку файла `students.txt`.

Выведите все строки, содержащие букву «a», в файле `students.txt`.

Выведите только строку с вашим ФИО, используя команду `grep`. После этого, используя флаг -x, выведите ТОЛЬКО полное совпадение в строке.

Замените своё имя на любое другое и выведите результат на экран (без изменения файла).

Замените в файле сегодняшнюю дату на завтрашнюю и сохраните изменения только в новом файле `studentz.txt`. Обязательно убедитесь, что оригинальный файл не изменился!

Создайте жёсткую и мягкую ссылку для `studentz.txt`. Проверьте содержимое обоих ссылок и то, как они выглядят через `ls`.

Удалите оригинальный файл `studentz.txt`, посмотрите, как изменилось содержание обоих ссылок и то, как они выглядят через `ls`.
