# Задание №3
## Основы работы с сетевой передачей данных

Определите свой адрес. Используя `grep`, выведите только строчку с вашим IPv4.

В вашей персональной директории создайте директорию `network_lab/`. Перейдите туда.

Выберите коллегу для парного задания. Узнайте от коллеги его IP адрес и передайте ему свой.

Проверьте доступность отправки пакетов коллеге по его адресу.

Создайте файл `message.txt` через `cat > message.txt << EOF`. Сообщение должно быть оформлено при помощи команд `hostname`, `whoami`, `pwd` и `date` В нём должно быть содержание следующего вида:

`Привет от <Ваше ФИО>!`

`Это сообщение от пользователя <имя вашего пользователя>, с компьютера: <имя вашего хоста>.`

`Сообщение находится в директории <расположение директории>.`

`Сегодняшняя дата: <дата>.`

Посмотрите права `message.txt`. Затем, модифицируйте их на ваше усмотрение, но так, чтобы новые права были отличны от начальных.

Переименуйте `message.txt` в `message_from_<ваша фамилия на английском>.txt`.

Отправьте этот файл вашему коллеге в папку `network_lab/` его персональную директорию.

Зайдите через `ssh` на компьютер вашего коллеги и проверьте, что файл действительно передался по сети. Допишите в конец файла строку `Файл был получен компьютером <имя хоста подключённого компьютера>!`.

Вернитесь в свою рабочую директорию на свой компьютер и скопируйте с удалённого компьютера модифицированный файл. Посмотрите его права и содержание.
